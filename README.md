# Khushi Kumari - Vintage Tech Portfolio

A curated portfolio website for **Khushi Kumari**, Software Developer & Cybersecurity Researcher specializing in Post-Quantum Cryptography at CSIR-NPL.

The site is built with a **vintage hacker aesthetic meets minimalist elegance** theme. It focuses on technical philosophy, systems engineering, C++ neural network implementations, cryptography research, and algorithmic problem-solving.

## ⚡ Technical Features

1. **Pure Vanilla Web Architecture**: Built strictly with standard HTML5, CSS3, and JavaScript (ES6+). Zero frameworks, zero heavy dependencies.
2. **Narrative Block Structure**: Projects presented as technical deep dives detailing **What I Built / Benchmarked**, **What Makes It Hard**, and **Why It Matters**.
3. **Interactive Vintage CLI Terminal**: Interactive terminal drawer widget at the bottom of the site. Visitors can type commands like `help`, `about`, `quantumvault`, `mindflow`, `neuroscale`, `stats`, and `contact`.
4. **Scroll Fade-In Animations**: Uses the performant `IntersectionObserver` API for smooth 200ms section scroll transitions.
5. **Cream & Amber Dark Mode Toggle**: Instant switching between Cream vintage print layout and Amber/Gold dark terminal theme.
6. **Responsive Design**: Fluid mobile and desktop styling supporting screens down to 360px.
7. **Copy Email Utility**: Quick one-click email copying with toast notification feedback.

## 🚀 How to Run Locally

Since this project requires no build tools or compilation steps:

### Option 1: Direct File Access
Simply double-click `index.html` or open it directly in any modern browser.

### Option 2: Python Local Server
Run a light HTTP server inside the project root:
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000` in your web browser.

### Option 3: Node `serve` / `live-server`
```bash
npx serve .
```

## 📦 Deployment Instructions

This repository is ready for instant 1-click deployment on free static hosting services:

### Deployment on GitHub Pages
1. Push this project to a GitHub repository.
2. Go to **Settings > Pages**.
3. Under **Branch**, select `main` and root `/`.
4. Click **Save**.

### Deployment on Netlify / Vercel
1. Connect your repository to Netlify or Vercel.
2. Leave build command empty (`No build command needed`).
3. Set publish directory to `.`.
