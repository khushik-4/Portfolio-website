## Running Locally

Clone the repository:

```bash
git clone https://github.com/khushik-4/Portfolio-website.git
```

Navigate to the project:

```bash
cd Portfolio-website
```

Open `index.html`

or start a local server:

```bash
python -m http.server 8000
```

Then visit:

```
http://localhost:8000
```
